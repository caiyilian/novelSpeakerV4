# 整段场景证据链质量架构（2026-07-16，07-18 更新）

## 目标

将第 1 至第 5 卷人工复核答案的宽松准确率从当前 89.94% 提升到 98% 以上。运行时间、API 调用次数和 token 消耗不作为优化目标；唯一优先级是跨卷稳定准确率。

实现必须保持作品无关：源码中不得出现任何特定小说角色名、组织名、地点名或剧情规则。人物、别名、身份和场景关系只能从当前小说原文、运行时状态及证据库动态获得。

## 已被上一轮实验否定的假设

1. 同一个模型、同一份上下文和近似提示词重复五次，不构成五条独立证据链。
2. 4/5、5/5 或终审多数不能单独作为覆盖基线的条件。
3. 前后邻居属于同一人物，不代表中间对话必然属于另一人物。
4. 把局部支持票数展示给终审会产生锚定，终审不再独立。
5. 只优化候选选择器无法达到 98%；当前候选池即使由完美裁判选择，理论上限也只有 96.13%。

9. `quality` / `quality-v1` / `ensemble` / `legacy` 四种模式并存；

14. 代码从原文位置和标点生成确定性引号边界约束，防止把上一句的后置归属错误向前绑定给目标句；

16. 泛称与实名冲突不进入话轮 A/B 辩论，交由身份规范化链；

## 第一层：稳定场景切分

场景切分只使用通用文本结构：

1. 对话之间的原文行距和叙事段长度；
2. 章节/幕/节标题形态；
3. 明显时间跳转或地点切换的通用叙事信号；
4. 最大对话数和最大原文跨度硬限制，保证 40K 上下文安全；默认最多 6 个对话轮次、180 个原文行；
5. 超过硬限制时优先在叙事最厚的边界处分块。

切分结果必须稳定：同一场景块内任意目标对话都映射到同一个 `scene_id`。首次遇到场景时完成整段求解，后续对话读取缓存，不重新形成目标中心不同窗口。真实 API 测试中，12 至 17 轮的结构化 assignment 容易触及 4096 输出上限；为给五份完整映射保留稳定输出空间，当前默认收紧到 6 轮。

## 第二层：五个不同职责的完整场景映射器

每个映射器都必须返回场景内每一条对话的结构化 assignment，不能只返回目标行。

### 结构归属映射器

只处理可验证的语法和叙事绑定：前置/后置说话动词、动作主体、引号嵌套、文字/声音/内心边界。不得使用角色性格、口癖、职业或题材知识猜测。

### 全场景时序映射器

从场景第一条对话开始，逐条维护参与者和发言序列。它必须显式说明每一次说话人切换是否有原文证据；没有证据时允许同一人物连续发言，不得强制交替。

### 对话连续性映射器

重点检查回应对象、问答关系、称呼和被叙事动作打断的位置，但话题相似、角色口癖和“某人更像会说这句话”不能作为独立证据。

### 对话行为映射器

逐条识别问答、请求回应、纠正确认、告别回应、解释延续等对话行为。它只能在原文关系成立时推导换人，不能把所有相邻句机械交替。

### 逆序映射器

从场景末尾反向重建序列，先固定后置归属和后方明确锚点，再向前检查目标。该视角用于挑战正向阅读产生的先入锚定。

五个映射器使用不同任务说明和证据视角。后续调查器和裁判只看到去重、匿名后的完整序列假设；相同序列只出现一次，不展示模型来源或支持票数。

## 第三层：五类目标证据调查

当前质量优先实现会为每个目标运行目标证据调查器，不以速度或 token 为条件跳过：

1. 输入完整场景原文、匿名候选标签及各自引用的原文行；
2. 不显示候选来源和支持票数；
3. 可调用 `read_novel_lines` 扩大上下文；
4. 可调用 `search_novel` 查找候选身份、首次命名和别名关系；
5. 不限制在已有候选内，可以从原文提出新候选；
6. 必须给出目标绑定证据、证据类型、置信度和反对其他候选的理由；
7. 没有足够证据时明确返回 unresolved，而不是靠交替强猜。

五类调查职责分别是：精确语法绑定、无候选开放世界识别、前后话轮边界、人物身份/引号容器、跨连续引号块的延迟归属。调查器第一轮允许自由调用原文扩读、全文搜索或证据提交工具。若某轮完全没有工具调用，下一轮只开放并指定 `submit_target_evidence`；这样保留自主调查机会，同时防止模型连续多轮输出近乎相同的长篇分析。若某个 key 不执行指定工具，底层 fallback 会立即尝试下一个 SenseNova key。

这一层的首要指标是候选召回率：上一轮有 271 条最终错误从未出现正确候选，新架构必须显著降低该数量。

## 第四层：对抗式边界仲裁

当基线、场景图、调查员或初审形成两个不同人物候选时，系统才启动边界仲裁；只有一个人物候选时不额外消耗调用，泛称与实名冲突则转交身份链。

1. 候选 A、B 各由独立代理生成最强支持证据、最强反证和最弱假设；
2. 三名裁判分别正向、逆向和按修辞链阅读，其中一名交换 A/B 展示顺序；
3. 裁判必须比较“与前句同人/换人”和“与后句同人/换人”四种关系，不能只看最近被提名人物；
4. 三名裁判全部有效且选择同一人物时，形成初裁共识；
5. 初裁分歧时，两名复审员交换顺序做完整反事实序列重建；两人一致后，还必须有至少三张场景图，或两张场景图加两份调查报告支持；
6. 任一层仍分歧则返回 unresolved，不把多数票包装成证据。

系统同时生成通用的确定性边界说明。例如，“上一句后第一条包含发声动词、但不以冒号结尾的叙事”只能后置绑定上一句，不能跨过来绑定目标；“紧邻下一句、以冒号结尾的发声叙事”只引出下一句。该说明来自标点、位置和通用发声动词，不包含作品专有信息。

修辞复述也按双假设处理：“也就是说”等改写既可能是另一人回应，也可能是同一人展开，必须结合叙事换人证据判断，不能自动交替。

## 第五层：证据裁判与覆盖门

覆盖基线的条件按可靠性从高到低排列：

1. **确定性直接归属**：目标附近原文明确绑定说话人或明确证明非人物发声。
2. **身份规范化**：原文或已验证证据库明确证明泛称/简称属于已命名人物。
3. **完整证据链**：场景序列候选、目标深查和对抗边界证据在不依赖交替假设的情况下共同排除基线。
4. **证据不足**：保留基线，记录 unresolved，不把多数票当证据。

新增边界仲裁不能越过三类更高优先级保护：确定性直接归属、确定性人物/非人物容器、相邻动作无发声动词歧义。07-18 的真实保护样例中，五张场景图、五个调查员、初审和三名边界裁判全部选择错误候选，但 Python 仍识别到目标附近只有动作、没有说话绑定，因此保留正确基线。

任何仅由交替、支持数、话题、口癖、职业、物种或角色性格产生的判断都不能覆盖基线。

`direct` 不是模型自报即可成立。Python 会再次读取引用行，只有通用语法上能找到“候选主体 + 说/问/回答/喊等发声动词”的绑定，才允许直接覆盖。某人摇头、注视、坐起或做出其他动作后紧接一段引号，既可能是本人继续，也可能是对方回应，因此单纯相邻动作不得作为直接归属；遇到这种歧义时，纯序列共识也不能覆盖有效基线。

人物/非人物边界也由通用原文结构复核，而不是仅相信终审自报：

1. “没有说出口”“省略掉这句反驳话语”“心里想”等容器表明目标文本未被人物实际发声；
2. “说到一半”“刚开口”“话刚出口”等容器表明发声已经开始，被打断的内容仍属于人物；
3. 明确绑定到已命名人物的笑、哭、咳嗽、呻吟、鼾声等身体发声仍归该人物，而不是归入非人物发声；
4. 上述规则只识别叙事结构和发声状态，不包含任何作品角色、场景或题材词。

## 后续阶段：场景级二次一致性检查

下列“场景结束后回写此前结果”的二次处理尚未进入当前流式写入代码。本轮已经实现的是写入前的完整序列映射、目标调查和覆盖门；若难例集证明仍有大量跨目标不一致，再实现延迟提交和场景级回写，不能把设计稿当作已完成代码。

第一遍逐条写入前，场景映射缓存保留完整序列。场景结束时检查：

1. 同一引号行的多个片段是否被错误拆成不同人物；
2. 没有叙事中断时是否无证据地频繁切换；
3. 有明确说话动词时是否被其他弱证据覆盖；
4. 同一已命名人物是否在同场景内退化成多个泛称；
5. 人物/非人物发声判定是否与引号容器一致。

若发现冲突，只重新调查冲突目标，不整场无条件重投票。

## 真实 SenseNova 冒烟结果

所有样本均在隔离的 `tmp/` 数据目录运行，只复制小说原文；参考答案没有进入任何模型消息，只在结束后比对。

1. **错误终审保护**：基线与人工答案一致，三个场景映射也一致，但两个调查分裂、终审提出错误候选。覆盖门拒绝改动，保留正确基线。
2. **相邻动作陷阱**：初版中三个映射、两个调查和终审都把“某人做动作后另一人回应”误当成动作主体发言，确实改坏。加入发声动词语法校验后，同一真实样本保留正确基线；即使模型一致错误，也不能越过门槛。
3. **真实直接证据纠错**：旧基线把叙述行内的嵌套引号判成非人物发声；原文同一句明确出现“某人原本要说”。三个映射、两个调查和终审引用该行，Python 语法校验通过，最终纠正为人工答案中的命名人物。
4. **工具协议与场景规模**：字符串 `tool_choice=required` 对 SenseNova 不可靠，改为指定具体函数；轮询成员不调用必需工具时立即换 key。场景上限由 18、12、8 逐步收紧，当前五映射版本默认 6 轮，以保证结构化输出完整。
5. **未说出口边界**：旧基线把“被省略、未实际说出”的引号归给人物。通用容器复核将其纠正为非人物发声。
6. **被打断的已开始发声**：终审曾把“说到一半”的人物话语误判为非人物。完整场景共识加“已开始发声”结构恢复了人物归属。
7. **人物身体发声**：终审曾把原文明绑到命名人物的鼾声判为非人物。人物发声绑定门恢复命名人物。
8. **身份搜索**：基线只给出泛称，目标搜索代理从原文身份链找回完整姓名；答案没有参与搜索。
9. **质量代理失败降级**：真实样本曾出现六个 key 都不提交某个指定场景映射工具。现在该映射记为无效，其他映射、调查和裁判继续工作，整条标注不再崩溃。
10. **工具轮耗尽后的身份收口**：SearchAgent 曾经已经读到远处身份揭示，却因第 8 轮仍在调用工具而直接返回未找到。现在最大轮数后会强制调用 `submit_identity_result`，真实样例成功将临时泛称规范化为完整姓名。
11. **后置归属作用域**：真实连续对话难例中，模型曾把“上一句之后的某人说道”错误向前绑定给目标。代码现在把该行标成“已被上一句消耗”，目标由后方锚点、修辞链和场景序列重新判断。
12. **镜像边界裁判仍会相关性犯错**：首版三裁判在同一难例上曾一致犯错；加入确定性作用域说明后，三裁判变为一票前候选、一票未决、一票后候选，最终由三张完整场景图和专门解码器纠正。说明提示词有所改善，但不能把同模型多次调用视作真正独立证据。
