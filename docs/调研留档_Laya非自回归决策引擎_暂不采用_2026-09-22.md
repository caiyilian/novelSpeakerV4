# 调研留档：Laya 非自回归决策引擎（暂不采用）

记录日期：2026-09-22。结论：**调研过，对我们当前主线帮助有限，暂不采用。** 本文留档以备日后回看。

来源：https://github.com/NandhaKishorM/laya （Apache 2.0，Convai Innovations，2026-09 发布）

---

## 一、它是什么

**非自回归（non-autoregressive）的 "System 1" 决策引擎**——不做文本生成，而是对任意状态（text / email / ticket / JSON）做「类型化决策」，单次前向传播 **33 ms**（T4 GPU）。

| 题型 | 输出 | 用途 |
| --- | --- | --- |
| `choice` | 最高标签 + 各选项概率 + 置信度 | 分类 / 路由 / 意图 |
| `score` | 有序量表上的期望值 + 分布 | 紧急度 / 严重度 |
| `noul` | 校准过的 P(true)，0~1 | 是 / 否判断 |

核心卖点：**"No text generation, so nothing to parse and nothing to hallucinate."** —— 因为不生成文本，所以没有解析失败、没有幻觉空间。

其他特点：
- 本地自托管（无远程 API），Hugging Face 权重 `convaiinnovations/laya`
- 三个 checkpoint + `Router` 按脚本/语言毫秒级选：`laya`（ModernBERT-large 421M / 512 ctx / 英文）、`laya-multilingual`（mmBERT-base 322M / 1024 ctx / 100+ 语言）、`laya-typed-decisions`（ModernBERT-large / 1024 ctx）
- **RLCD 训练**（严格适当评分规则 + GRPO 式策略梯度）→ 置信度统计上有意义，可做 confidence gating
- 微调 notebook（Kaggle 免费 2xT4，~4-5h）

## 二、为什么对我们帮助有限（四个硬阻碍）

| # | 阻碍 | 说明 |
| --- | --- | --- |
| 1 | **违反项目硬约束** | Laya 是本地 BERT 模型，不是 `deepseek-v4-flash`；用它即破坏"运行时只用 v4-flash"这条线 |
| 2 | **基座零样本近乎随机** | README 原话：*"Treat Laya as a fast base to specialise, not as a zero-shot decision engine."* typed-decisions 零样本仅 **0.36**（随机基线 0.318），微调后才 **0.766**。小说说话人数据它从没见过 |
| 3 | **上下文太小** | 512~1024 token；而本项目核心难点是**前向引用**（"女孩"后文揭示为"赫萝"需回填），需全场景/全卷信息。BERT 架构处理不了这种长程依赖 |
| 4 | **高基数 choice 会崩** | choice 需预定义 criteria，但我们的说话人候选是**动态的**（账本几十角色 + 泛称 + 无人称引语）。README 自认：77 选项的 Banking77 每标签只剩 3-4 token，精度 0.87→0.43 |

## 三、唯一可能的边缘切入点（未来备选）

若哪天放开"只用 v4-flash"约束，Laya 的合理用法是**微调成一个"无人称引语二分类器"**（`noul` 题型：「这处引号是不是人在说话？」）：
- 低基数二分类，正是 Laya 的优势场景（`noul` 在其基准上 0.857，是三题型里最高的）
- 直击本项目最大错误块（236 条无人称引语过判）
- 硬件：用户有 6 台 4090，可微调；但训练数据仅 7009 条偏少

可作**本地毫秒级预筛 / 置信度门控**：先让 Laya 二分类筛掉明显非发言的引号，再交 v4-flash 精细归因。

## 四、概念印证（唯一有价值的收获）

Laya 的哲学——**"类型化输出 + 不生成文本"**——与本项目后续方案的**结构化提交（`submit_label` 工具替代自由文本解析）**方向完全一致。这从侧面印证了我们踩过的解析污染坑（D 编号回显、"说话人"字面污染）的正确解法：**让模型的输出走 schema 约束，而不是事后用字符串猜**。

**暂不采用。** 它属于"模型选择"范畴，而本项目已锁定 `deepseek-v4-flash`。留档备查。
