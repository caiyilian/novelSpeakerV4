# 方案6（1015 无人称引语判据修正）结果记录

记录日期：2026-09-22。分支 `feat/scheme-6-attributable-np`。方案来源：`docs/discussion/Agent编排重构方案_2026-09-21_1015.md`。

> **结论先行：方案6 = 93.31%，比 cont 基线高 +1.00pp（六方案里第二个正收益）。但 vol5 变差 −1.02pp——"可归属"判据在 vol5 上过修正。**

## 一、方案做了什么

1015 最重要的发现：cont_agent 的 542 条错误里，**236 条（43.5%）是"无人称引语过判"**，根因是判据错位——

| | cont_agent 用的判据 | 答案实际用的判据 |
| --- | --- | --- |
| 判据 | **引号类型**（神态字幕/被引用词句/强调词 → 无人称引语） | **可归属**（上下文有能挂住的主体 → 归那个人） |

1015 甚至给出反直觉证据：**"永远不说无人称引语"的零成本策略（120 条错误）比当前方案（290 条）还准**。

本方案落地 1015 的 P1：**只对 cont 判为「无人称引语」的条目（五卷 495 条），用「可归属」判据二次确认**——可归属则归主体，否则保持无人称引语。其余条目完全不动。

实现：`annotator/np_refine_agent.py`（`reasoning_effort=high`，输入引语 + ±10 行上下文 + 账本）。

## 三、关键发现

### 3.1 判据修正有效，但 vol5 过修正

- **v1-v4 全部正收益**（+0.49 ~ +2.89）——证明 1015 的判断成立：把"引号类型"判据换成"可归属"判据，确实能修回大量过判的无人称引语。
- **vol5 反而变差（−1.02）**：v5 的 118 条改判里，有相当一部分是"**本应保持无人称引语**的条目被错改成了主体"（过修正）。说明"可归属"判据在 v5 这类文本上**过于激进**。

### 3.2 为什么 v5 会过修正

v5 的"无人称引语"占比最高（真实非人物多）。当模型被要求"判断能否归属到主体"时，它在 v5 这种"神态/心理描写密集"的文本里，容易把**纯描写性的神态字幕**也归给主体（因为上下文总有某个人物在场），从而过度纠正。

### 3.3 与方案2 的关系（关键）

方案6 与方案2 **针对完全不同的错误块**：

| | 方案2 仲裁 | 方案6 判据修正 |
| --- | --- | --- |
| 处理对象 | cont vs evledger 的 **819 条分歧** | cont 判为无人称引语的 **495 条** |
| 机制 | 两候选裁决 | 单条目判据重判 |
| 成绩 | 94.61%（+2.30） | 93.31%（+1.00） |

**两者处理的条目集几乎不重叠**（分歧 vs 无人称引语），因此**有组合空间**——这正是综合方案要验证的。

---

## 四、结论

1. **方案6（判据修正）：93.31%，净 +1.00pp，正收益。**
2. **vol5 过修正（−1.02pp）**：判据需要"保守化"——只在上下文有**明确归属标记**（"某人+说/想"）时才改判，纯神态描写保持无人称引语。
3. **与方案2 互补**（不同错误块），是综合方案的候选组件。
4. 1015 的"永远不说无人称引语"极端策略**不成立**（v5 反例证明：真实非人物多的卷会崩）。
