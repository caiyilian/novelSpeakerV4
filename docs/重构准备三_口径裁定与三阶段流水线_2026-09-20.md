# 重构准备三：口径裁定、多模型交叉验证与三阶段流水线

记录日期：2026-09-20。承接《重构准备_冻结清单_错误归因与强模型基线》与《重构准备二_口径重建_分层实验集与工具调研》。

本轮由用户授权自行裁定标注口径，并允许与 `deepseek-v4-pro` / `glm-5.2` / `kimi-k3` 自主讨论方案。仍然没有修改项目代码，没有改动 `data/` 与 `backup/`。

## 1. 「非人物发声」的裁定

### 1.1 用户交办的原话

> 「非人物发声」这个是我当时不知道要用什么标签，就随便写了这个，有些是人物心理描写，有些是纯语气词，有些是比如风声之类的，我也不知道怎么给出参考答案比较好，这一块你可以自己判断。

按此授权，本轮用**多模型独立提方案 + 多模型独立判例 + 多数票**的方式来做决定，而不是我自己拍一个。

### 1.2 第一步：三个模型独立提出分类法

给三个模型同一批材料（280 条非人物标签里分层抽出的 47 条实例），要求它们各自设计一版互斥、完备、可判定的引号用途分类法。

| 模型 | 提出的类别 | 内心独白裁定 |
| --- | --- | --- |
| **glm-5.2** | 实际口头对话 / 书面文本内容 / 引用与惯用语 / **内心独白** / 语义转述 / 神态与表情描述 / 拟声词 / 特定词语与专有名词 / 未发生或假设的话语（9 类） | **不算发声**，归「没人说话」一侧 |
| **kimi-k3** | 角色现场对话 / 假设或追述的他人话语 / **内心独白（M1）** / 表情与姿态的拟话语 / 术语说法与文本指称 / 拟声拟态词 / 叙述中嵌入的残缺引语（7 类） | **不算发声**，归「没人说话」一侧 |
| **deepseek-v4-pro** | 角色对白 / **角色内心独白** / 角色拟声 / 环境拟声 / 转述性引语 / 铭文与文书（6 类） | **算「有人说话」**范畴，但独立于对白（无声的语言行为） |

**关键分歧**：内心独白到底算不算「有人说话」——2:1 认为不算。

**关键共识**（比分歧更重要）：

1. 三者都认为内心独白**必须单独立类**，不能和引用词句、拟声混在一起。
2. 三者都保留「可归属到某个主体」这一信息维度——即使把它划到"没人说话"一侧，也仍然知道是谁在想。
3. 三者都指出最大风险是**转述性引语与真实对白的边界**，且都同意这条边界必须靠**引导动词**判定，不能靠语感。

### 1.3 第二步：三个模型独立判例

把 226 条字面标为「非人物发声」的实例（含上下文）交给三个模型，逐条判断"这处引号能不能明确归属到文中某一个具体人物"。

| 判定结果 | 条数 | 占比 |
| --- | ---: | ---: |
| **三模型全票「无归属」** | **211** | **93.4%** |
| 三票全为「可归属」 | 5 | 2.2% |
| 2 票可归属 | 3 | 1.3% |
| 1 票可归属 / 2 票无归属 | 7 | 3.1% |

判定为「可归属」的 8 条，全部是**原文有明确心理动词**的内心独白，且 7 条属于罗伦斯、1 条属于赫萝。抽样：

```
第3卷 L106: 罗伦斯心想「原来如此」，笑着回答说：
第3卷 L505: 罗伦斯心想「该不会……」于是把手伸向前
第3卷 L1431: 罗伦斯望向木窗外，在心里暗自说「根本没什么好担心的」
第5卷 L1120: 罗伦斯看着女商人的嘴边，心想：「原来如此，的确连半点胡渣都看不到。」
```

### 1.4 裁定结论（本轮决定）

**① 原标注基本是自洽的，不是"乱写"。**

226 条里 93.4% 被三个模型全票确认为"确实没有可归属的说话人"。用户担心的"混进了人物心理描写"，实际只影响 **8 条（3.5%）**。这个标签的**语义**是站得住的。

**② 真正的问题是标签名有误导性。**

「非人物发声」字面读起来像"不是人类发出的声音"，但它的实际含义是"这处引号不承载任何人的发言或思维"。这正是基线模型 7009 条里只肯输出 3 次的直接原因——它读不懂这个名字。

**决定：把这一类改名为「无人称引语」。**

定义：*该引号不承载任何具体人物的发言或思维（被引用的词句/说法/概念、叙述者给神态姿态配的字幕式引号、单独强调的词、环境声与拟声、被当作语言材料谈论的句子）。*

选这个名字的理由：长度与「非人物发声」相当，但不可能被误读成"非人类声音"；且它准确描述了**评判标准是"有没有归属主体"**，而不是"是不是人"。

**③ 内心独白归该主体，不归「无人称引语」。**

裁定理由：

- 原文已用心理动词明确指明了主体（`罗伦斯心想`），主体信息是确定的、可判定的；
- 项目现有答案 83% 的情况本来就这么做（81 条含心理动词的引语里 67 条归了人物），保持这一裁定可以让大多数样本不变，避免为了统一而制造新的历史不可比；
- 规则可由模型稳定执行：**有明确心理动词 → 归该主体；无明确主体 → 无人称引语**。

按此裁定，那 8 条从「非人物发声」改为对应人物，其余 218 条保留（仅改标签名）。

**④ 有 35 条复合标签是标注者在对冲，建议统一。**

答案里存在 `罗伦斯|非人物发声`（18 条）、`赫萝|非人物发声`（7 条）、`追兵|非人物发声`（3 条）这类"两个都给算对"的写法，合计 54 条含非人物标签的复合答案。这说明**当时的口径确实没定下来**。按本裁定，这些应统一为单一答案：能归属则写人，不能归属则写「无人称引语」。

### 1.5 一个必须承认的修正：我上一轮的判断错了

上一轮报告里我写过"基线 30% 的错误来自口径问题"。**本轮验证推翻了它。**

按 1.4 的裁定重算三方结果（严格修订 = 只认新标签；宽松修订 = 新旧都认）：

| 方案 | 原口径 | 修订后（严格） | 修订后（宽松） |
| --- | ---: | ---: | ---: |
| 旧系统 09-01 | 94.19% | 94.15% | 94.22% |
| 单次基线 | 88.23% | 88.30% | 88.32% |
| 两步法 | 88.63% | 88.71% | 88.73% |

**口径修订对总分的影响不到 0.1 个百分点。**

结论要改写成：

> 「无人称引语」这一类**不是口径问题，是真实的模型能力缺口**。基线在这 280 处机会里只输出过 3 次，贡献了 246 条错误（占 7009 条的 3.5%）——这是 5.96 个百分点差距里最大的一块之一。模型确实能做到（拆成独立任务后召回 91.36%），但它在联合任务里**行为上不会去做**。

这也说明：**用多模型交叉验证是有价值的，它拦住了一个会导致资源投错方向的错误结论。**

## 2. 两步法原型：账本约束的力量与不稳定

按调研得到的 Audiobook Creator 结构，做了"先建角色账本 → 再逐条归因"的两步原型（`tmp/deepseek_probe/twopass_annotate.py`）。

第 5 卷（最差的一卷）的错误类型变化：

| 错误类型 | 单次基线 | 两步法 | 变化 |
| --- | ---: | ---: | ---: |
| **实名降级为泛称** | 48 | **3** | **−45** |
| 实名与实名互换 | 73 | 78 | +5 |
| 泛称与泛称不一致 | 30 | 30 | 0 |
| 泛称误判为实名 | 3 | 6 | +3 |
| 非人物发声误判为人物 | 82 | 85 | +3 |
| **合计错误** | **236** | **202** | **−34** |

**「实名降级为泛称」几乎被彻底消除（48 → 3）。** 这正是账本该起的作用：一旦全卷角色名被固定成一份清单，模型就不会一会儿写实名、一会儿写职业。

但五卷总体只是 **88.23% → 88.63%（+0.40pp）**，而且逐卷方向不一致：

| 卷 | 单次基线 | 两步法 | 差 |
| --- | ---: | ---: | ---: |
| 1 | 90.88% | **93.62%** | +2.74 |
| 2 | 90.11% | 88.35% | **−1.76** |
| 3 | 91.60% | 89.38% | **−2.22** |
| 4 | 85.71% | 86.29% | +0.58 |
| 5 | 83.82% | **86.15%** | +2.33 |

第 1 卷涨 2.74pp，第 3 卷跌 2.22pp。**单个结构改动带来的收益不稳定**，这与旧项目历史上"每一层都在某些卷涨、某些卷跌"的模式是同一现象。

需要说明的一个混杂因素：两步法同时改了归因提示词（加了「无人称引语」和内心独白规则）和加了账本，两者效果没有分离。这也是下一步要做消融的原因。

## 3. 三阶段流水线（`pipeline_v1.py`）

把本轮验证过的三块拼成完整流水线，每阶段独立调用、独立落盘：

| 阶段 | 做什么 | 已验证的依据 |
| --- | --- | --- |
| **A. 引号用途判定** | 全卷正文 + 编号清单 → 每处判 A(实际发言) / B(非实际发言) | 独立任务时召回 91.36%（联合任务 0%） |
| **B. 角色账本** | 全卷正文 → 全部角色实体 + 别名/泛称归并 + 证据行号 | 消除实名降级为泛称（48→3） |
| **C. 受约束归因** | 只对判定为 A 的引语归因，候选人限定在账本内 | 账本强制标签一致 |

设计要点：**C 阶段只处理 A 判定为真实发言的引语**，B 判定的部分直接落「无人称引语」。这样"是不是发言"和"是谁说的"两个问题在不同的调用里回答，模型不会互相污染。

### 3.1 v1 结果：**直接串起来是负收益**

| 卷 | 单次基线 | 两步法（仅账本） | 三阶段流水线 v1 | 流水线 vs 基线 |
| --- | ---: | ---: | ---: | ---: |
| 1 | 90.88% | **93.62%** | 89.10% | **−1.78** |
| 2 | 90.11% | 88.35% | 未完成 | — |
| 3 | 91.60% | 89.38% | 85.60% | **−6.00** |
| 4 | 85.71% | 86.29% | 未完成 | — |
| 5 | 83.82% | **86.15%** | 80.67% | **−3.15** |

**三卷全部变差，最差一卷掉 6 个百分点。**

### 3.2 归因：A 阶段的高召回是用极低精确率换来的

以第 1 卷为例，A 阶段判定 61 处为"非实际发言"，而该卷真值里这类引语只有 **4 处**：

| A 判为 B 的 61 条构成 | 条数 |
| --- | ---: |
| **超短引语**（「唔。」「咦？」「……」≤8 字） | **41** |
| 其他 | 12 |
| 内心独白 | 5 |
| 神态姿态 | 2 |

**真凶是超短引语。** 那些「唔。」「咦？」在真值里都是**真实发言**，模型却因为"引语短得不像一句能说出口的话"判成了 B。加上 5 条内心独白——而那 5 条恰好**违反了第 1.4 节我自己刚刚下的裁定**（明文要求"有明确心理动词则归该主体"）。

两处都是我的提示词写错了，不是模型的问题：

- v1 的 A 阶段写着"引号内若不是一个可以独立说出口的句子，多半是 B"——这条直接把短语气词推向 B；
- v1 的 A 阶段写着"内心独白（有「心想／暗自说／脑海里」等标记）判 B"——与 1.4 的裁定相反。

**修正是两句话的事**（见 3.3），但这一轮负结果的真正价值在于三条方法论结论：

1. **在不平衡类别上，精确率比召回率重要。** 非对话引语在全集里只占 4%，所以一个误判会毁掉一个本来正确的标签，而一个漏判只是少拿一分。召回 91% / 精确 49% 的组合在总数上是**净亏**的。
2. **"独立任务召回 91%"不等于"串进流水线就能用"。** 单独的判别实验只测了召回，没有测它对下游的破坏力。任何新阶段都必须做**端到端**测量，而不是只看它自己那一层的指标。
3. **旧项目的"独立发声类型任务"失败，原因大概就在这里。** 旧系统也加过独立发声类型判断层，同样没有收益——现在有了可解释的原因。

> 注：本节的 v1 提示词错误（超短引语、内心独白）属于实现缺陷，已在 `pipeline_v1.py` 修正；修正后的结果见 3.3。

### 3.3 修正版对照：修好提示词也没救回来

修正内容：① 明确"短促语气词/应答词/省略号仍算 A"；② 内心独白改为判 A 并归该主体；③ 判 B 必须能指出元语言标记，否则一律判 A。

| 卷 | 单次基线 | 两步法 | 流水线 v1 | 流水线 v2（修正后） |
| --- | ---: | ---: | ---: | ---: |
| 1 | 90.88% | **93.62%** | 89.10%（B=61，真值 4） | 88.88%（B=38，真值 4） |
| 5 | 83.82% | **86.15%** | 80.67%（B=159，真值 81） | 未完成（A 阶段输出超限） |

过判从 61 条降到 38 条，**但准确率没有回升（89.10% → 88.88%）**，仍然低于单次基线的 90.88% 和两步法的 93.62%。

原因在第 1 卷的错误构成里：`泛称误判为实名` 从 22 涨到 **33**，`实名与实名互换` 从 82 涨到 **84**。这一版的账本只抽出 **15 个实体**（两步法那版是 19 个），实体抽少了，模型就只能往实名上硬套。

**结论：三阶段串联在本轮没有成功。** 不是某一个提示词的问题，而是"A 阶段判一次、C 阶段再判一次"这个结构本身让两次判断互相牵制，且 A 阶段的误差会不可逆地传导到最终结果——**没有任何机制能在 C 阶段纠正 A 阶段的误判**。

这与旧系统历史上"每加一层，误差就多一次传导机会"是同一个失败模式。

## 4. 平台层发现（可复用的坑）

本轮踩到并定位了几个模型池的参数问题，都会直接影响后续任何批量任务：

### 4.1 批量任务必须显式关闭推理

| 模型 | 默认行为 | 批量任务（200+ 条）的实际后果 |
| --- | --- | --- |
| `deepseek-v4-flash` | 有推理 | 不关推理会烧掉全部输出预算 |
| `deepseek-v4-pro` | 有推理 | `max_tokens=16384` 被 16384 个 reasoning token 全部占满，`content` 为空 |
| `glm-5.2` | 有推理 | 同上（小任务时 6176 个 reasoning token 还撑得住，226 条任务直接爆） |
| `kimi-k3` | 推理较少 | 226 条任务只用了 6493 个 reasoning token，可正常完成 |

**必须显式传 `reasoning_effort: "none"`**（或 `thinking: {"type": "disabled"}`）。整卷批量输出场景下，开推理会直接导致任务失败——实测第 5 卷 390 秒只完成 152/1459 条。

合法取值：`low / medium / high / xhigh / none`（传非法值网关会返回明确的字段校验错误）。

### 4.2 `kimi-k3` 的参数限制

`kimi-k3` 对 `temperature` 和 `max_tokens` 会返回 **HTTP 400**，只接受 `model` + `messages`。必须为它单独走一个最简 payload 分支。

### 4.3 其他

- `response_format: json_schema` **不被支持**：预算会被 reasoning 吃光，`content` 为空。结构化输出只能用提示词约束。
- 工具调用（function calling）**正常可用**，已验证两轮工具循环。
- 1M 上下文**真实可用**：整卷正文 + 引语清单约 9.5 万 token，占上限不到 10%。

## 5. 修正后的结论

### 5.1 三方总账（五卷 7009 条，同一评分器）

| 方案 | 语义准确率 | 逐卷 | 每卷耗时 | 每卷模型调用 |
| --- | ---: | --- | ---: | ---: |
| **旧系统 09-01** | **94.19%** | 97.33 / 96.84 / 95.72 / 91.54 / 90.27 | 十几天量级 | 每条约 15–18 次 |
| 单次基线 | 88.23% | 90.88 / 90.11 / 91.60 / 85.71 / 83.82 | **约 60 秒** | **1** |
| 两步法（账本） | 88.63% | 93.62 / 88.35 / 89.38 / 86.29 / 86.15 | 约 70 秒 | 2 |
| 三阶段流水线 | 更低 | 89.10 / — / 85.60 / — / 80.67 | 约 320 秒 | 3 |

### 5.2 必须直说的结论

1. **「非人物发声」的语义是对的，名字是错的。** 改名为「无人称引语」；内心独白在有明确心理动词时归该主体。裁定依据是三模型独立提案 + 226 条逐条判例（211 条全票）。
2. **口径修订对总分影响 <0.1pp。** 我上一轮"30% 错误来自口径"的判断被推翻。这 246 条是**真实的模型能力缺口**。
3. **本轮尝试的三个新结构，没有一个接近旧系统的 94.19%。** 最好的两步法只比单次基线高 0.40pp，且逐卷方向不一致（第 1 卷 +2.74、第 3 卷 −2.22）。
4. **账本是本轮唯一被单独证明有效的组件。**「实名降级为泛称」在第 5 卷从 48 条降到 3 条——这是明确、可解释、可复现的改善。但它的收益会被其它环节的波动掩盖，所以**必须用分层实验集分别统计，不能用总分**。
5. **"独立任务指标好"不等于"串起来有用"。** 引号用途判定独立跑召回 91%，串进流水线后因为精确率只有 49%，反而让三卷全部变差。这是本轮最重要的方法论收获。
6. **不要把 98% 当作近期可达目标。** 专门训练的 BookNLP 在英文小说上说话人归因 B3 只有 86.4–89.9；本项目旧系统的 94.19% 已经高于这个量级。继续往上走的每一分都要靠真实证据推理，而不是靠加层。
