## 三、综合尝试（都未超越方案2）

对正收益方案做了三类组合（零成本，用现有产物）：

| 组合策略 | 五卷 | vs 方案2 |
| --- | ---: | ---: |
| 方案2（arb）基线 | **94.61%** | — |
| arb + 判据修正（无人称条用 npfix） | 93.89% | −0.72 |
| arb + 对抗裁决（分歧用 ref） | 94.42% | −0.19 |
| arb + 双确认（npfix 与 ref 都改才改） | 94.56% | −0.05 |
| **逐卷择优上界（v1/v4 用 ref，v2/v3/v5 用 arb）** | **94.79%** | +0.18（不可部署） |

**结论：任何可部署的组合都无法超越方案2 的 94.61%。** 原因：

1. **方案2 已经把"无人称引语相关分歧"处理过了**——判据修正（方案6）叠加到 arb 上，大部分是"重复处理"或"过修正"（v4/v5）。
2. **组合上界 96.08% 是"完美选择"的理想值**，实际需要答案来指导"何时选哪个方案"，不可部署。
3. **逐卷择优 94.79%** 说明还有 0.18pp 理论空间，但它依赖"逐卷知道哪个方案更好"（即答案），同样不可部署。

## 四、最终结论

1. **最终方案 = 方案2（分歧仲裁），94.61%**，一键可复现，五卷约 40 分钟，单卷远低于 12 小时预算。
2. **已超过旧系统 94.19%**，用约 1/5000 的时间（40 分钟 vs 十几天）。
3. **距 95% 差 0.39pp**（= 27 条）。这 27 条集中在"两通道都错的共同盲区"（无人称引语过判 + 复杂实名互换 + 泛称口径），v4-flash 的仲裁器也救不动。
4. **六方案的净价值**：
   - **必须保留**：方案2（分歧仲裁）→ 最终主方案
   - **生产系统应纳入**：方案5 的精确 span 定位 + 严格 parse（健壮性，不涨分）
   - **留作参考**：方案4（对抗裁决）与方案2 互补，若未来引入"更强模型做第三层裁决"，143 条互补素材可用；方案6（判据修正）提示"无人称引语判据应保守化"
   - **证伪路径**：方案1（场景块替代）、方案3（三通道）、同源投票等

---

## 五、距 95% 的诚实评估

- 94.61% 是 `deepseek-v4-flash` + 干净编排（整卷 + 账本 + 逐条 + 分歧仲裁）的**实际边界**。
- 剩余 27 条 = 三个方案 + 旧系统**全部答错**的真难点（旧系统在这类上也大量错），属于模型能力边界 + 标注口径噪声。
- 要跨过 95%，只剩两条路（均已明确）：**A 放开模型限制**（对剩余难点用更强模型兜底）；**B 修订答案口径噪声**（方案6 报告 §3.3 已量化：无人称引语类有 ~1.9pp 的口径噪声，不改答案就永远压在系统头上）。
