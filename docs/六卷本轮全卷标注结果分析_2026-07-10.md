# 六卷本轮全卷标注结果分析（2026-07-10）

## 范围与口径

本报告基于本轮已完成的六卷标注结果：第 1、2、3、4、5、8 卷。第 7 卷因短篇、心理描写和“非人物发声”占比明显不同，不纳入本轮横向指标。

统计时同时保留两种口径：

1. **严格准确率**：预测标签必须与答案标签的规范化文本一致。
2. **宽松准确率**：允许同一已命名人物的全名/简称包含关系，以及“旁白/叙述”等非人物发声同义标签。示例：`罗伦斯` 与 `克拉福•罗伦斯` 可视作同一人物。

宽松准确率更接近当前项目的标注目标，但它仍没有自动放宽“有名字的人物却输出职业或外貌泛称”的情况。依据当前约定，若人物在作品内有名字，应优先输出其名字；例如 `艾凡` 优于“磨粉匠”，而 `磨粉匠艾凡` 可接受。无姓名的路人角色则使用稳定泛称是合理的。

结论：当前严格 83.08% 不能直接解释为模型的说话人判断只有 83%，其中有 590 条只是全名、简称、旁白别名等表面标签差异。按更符合项目目标的宽松口径，整体为 **90.52%**；但仍有 753 条不能靠简单别名解释的错误，距 98% 目标还有显著差距。

若以 7,939 条达到 98% 计算，最多只能有约 159 条错误；当前需要再减少约 594 条宽松后仍错误。仅靠重新运行或换同级模型，预计不足以达到目标。

六卷日志显示，全部实际请求都由 `sense-nova-1` 到 `sense-nova-6` 完成，没有出现 Agnes、LongCat 或其他兜底模型主导某一卷的情况。每卷内六个 Key 的调用量也接近均分：

因此，本轮较低分数不是“某个失败的 fallback 模型拖垮一卷”造成的。轮询调度确实生效；问题主要在任务推理、参考答案的一致性和验证语义上。

将 1,343 条严格错误拆分后：

## 分卷观察

### 第 1 卷：95.11% 宽松准确率

总体最好，但剩余错误仍以主角二人短句互换为主。例如相邻两句均在讨论同一事物时，模型会过度套用“轮流说话”或根据“狼”等关键词猜测角色，而没有以相邻动作、回应关系和后置归属语句完成校验。

还存在“仿佛在说”“心里想”等叙述性表达：部分答案把它视作角色发言，模型则判为非人物发声。这里需要先统一标注政策，不能只通过提示词强推模型猜测。

最弱 100 条区间为 #1101–1200（91%）。

### 第 2 卷：92.28% 宽松准确率

第 2 卷的长尾问题明显：#1201–1300 只有 72%，#301–400 为 80%。除主角互换外，商行人员、追随者、牧羊女等“已命名人物与身份泛称”之间的答案标准仍不完全统一。

部分 `罗伦斯 -> 非人物发声` 样本实际上看起来像叙述或内心，说明不能机械假设答案永远正确。该卷已经人工复核过，但仍建议把“心理/叙述是否计入说话人”的规则写成可执行标准，再做一次针对性抽查。

### 第 3 卷：93.00% 宽松准确率，严格分数失真最严重

严格准确率只有 58.77%，但其中大量为可接受的全名输出：`罗伦斯 -> 克拉福•罗伦斯` 335 条、`阿玛堤 -> 费米•阿玛堤` 58 条、`巴托斯 -> 居伊•巴托斯` 19 条。这些按项目要求不应视作实质错误。

剩余 85 条仍主要是主角互换、人物与非人物发声边界，以及例如 `狄安娜 -> 狄安•鲁本斯` 这种不具备字符串包含关系、但可能是同一人物的别名。后者应该从本卷证据库动态学习别名关系，不能在代码中写具体小说人名。

最弱区间为 #501–600（81%）。

### 第 4 卷：90.33% 宽松准确率

`艾凡 -> 吉尧姆•艾凡` 119 条属于可接受的命名形式差异。实际问题集中在多人谈判和连续短句中：罗伦斯、赫萝、艾莉莎等人物容易被模型根据最近出现的名字或被提问对象误判为发言者。

最弱区间为 #201–300（80%）、#1101–1200（83%）。这说明错误不是只出现在开头，也不是简单的长期记忆衰退，而是特定多人场景的局部归因不足。

### 第 5 卷：88.42% 宽松准确率

第 5 卷是已复核卷中真正需要优先处理的一卷，#201–300 仅 62%。典型错误包括女服务生/红发女孩、酒吧女孩/女孩等无姓名人物的描述变化，以及罗伦斯、伊弗、芙洛儿•波伦之间的多方场景错配。

这里需区分两类问题：

1. 同一未命名路人由不同稳定描述指代，参考答案和模型输出可能语义等价；
2. 已命名人物之间互换，是模型的真实推理错误。

不能为了修复第一类而写入“商行”“追兵”“酒吧”等作品特化规则。应由通用的实体共指/别名证据来判断。

### 第 8 卷：81.51% 宽松准确率，当前最弱

第 8 卷的主要异常是 `店主 -> 泰德•雷诺兹` 51 条。若店主在前后文已经被命名为泰德•雷诺兹，按“有名字必须用名字”的规范，模型输出反而应该优于旧答案标签。因此，重新训练或改提示词前，应先优先人工核查这些参考答案。

该卷仍有大量伊弗、罗伦斯、赫萝、寇尔的多人场景互换，并存在叙述/旁白/角色内心之间的边界案例。最弱区间 #201–300 仅 50%，#301–400 为 62%，说明局部场景对话归因是核心瓶颈。

## 根因判断

### 1. 参考答案与输出规范尚未完全统一

第 3 卷的全名差异和第 8 卷的“店主/泰德•雷诺兹”说明，当前答案中同时存在名字、职业、外貌、组织身份等不同粒度的标签。验证器已经能处理部分表面差异，但参考答案本身仍会让正确的通用输出被算错，或者让不应接受的泛称被放过。

这必须首先通过人工复核和统一标注规范解决；模型提示词无法可靠替代标签政策。

### 2. 局部说话人归因不足

最大的真实错误类别是已命名人物互换。模型当前在短句中会把：

1. 最近出现的人物；
2. 被提问的人；
3. 上一句的发言者；
4. 语义上“更像会说这句话”的角色；

误当为当前发言者。尤其当动作归属出现在引号之后、或当前句需要结合前后两到三句才能判断时，错误明显增多。

### 3. “非人物发声”边界不是单纯模型能力问题

人物内心、叙述中暗示的发言、带引号的文本内容、作者旁白和真正台词之间，当前参考答案的处理有不一致迹象。宽松后仍有 132 条跨越了人物/非人物边界。若不先明确这类文本的标注准则，额外 agent 也只能在不同错误方向之间摇摆。

### 4. 轮询和上下文长度不是主因

本轮六个 Sense-Nova Key 的调用分布均衡，且没有某卷被异常 fallback 模型接管。错误最密集的区间也分布在中后段的具体场景，并非单纯从长上下文溢出或记忆衰退导致。

## 面向 98% 的后续方向（暂不实施）

1. **先固化答案政策**：明确“已命名人物、无名路人、组织成员、外貌描述、内心与旁白”各自的唯一答案写法；优先复核第 8 卷 `店主 -> 泰德•雷诺兹`、第 2 卷 `牧羊女 -> 诺儿菈•艾伦` 等高频样本。
2. **动态别名与共指证据**：由本卷文本、已标注历史和证据库学习“简称/全名/称谓/描述”的关联，验证和候选生成都使用该证据。不得在代码里写入任何特定小说的角色名、组织名或情节规则。
3. **高风险局部复核 agent**：只对存在多个近期候选人物、短句、前后归属提示或置信度低的对话触发；复核必须读取目标行前后窗口，尤其支持“引号后才出现说话人”的证据。
4. **独立的非人物边界判定**：先按统一政策判断是否应是人物发声，再在人物候选中归因；将“内心/旁白/引号中的转述”作为专门风险类别记录。
5. **把评估拆层**：持续输出严格、名称/别名归一后、人工确认语义等价后、真实错人四类指标。这样才能判断代码改动是否真的改善推理，而不是只改变标签字符串。

在开始下一轮大规模重跑前，建议至少完成第 8 卷高频样本和非人物政策的人工确认；否则 98% 的目标会被参考答案噪声遮蔽，也无法判断改动到底是否有效。
