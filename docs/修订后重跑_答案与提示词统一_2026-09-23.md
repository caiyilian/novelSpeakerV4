## 三、关键发现

### 3.1 改提示词成功：过判大幅减少（本轮最重要的验证）

| 指标 | 修订前 | 修订后 |
| --- | ---: | ---: |
| cont 输出的「无人称引语」 | 495 条 | **198 条（−60%）** |
| 答案里的「无人称引语」 | 281 条 | 114 条 |
| **过判量** | 214 条 | **84 条（−61%）** |

**改提示词（引号类型 → 可归属）确实把"无人称引语过判"消掉了六成。** 这是本次修改的直接目的，达成。

### 3.2 绝对分普遍下降的原因：评分口径变严，不是方案变差

修订后所有方案绝对分下降（−0.26 ~ −1.82pp），根因是**答案去掉了"对冲"的复合标签**：

- 修订前：`罗伦斯|非人物发声` 这类复合标签在宽松评分下**两个答案都算对**；
- 修订后：统一为单一标签，模型输出另一个即算错。

所以**绝对分不可跨口径比较**，要看的是**相对增益**。

### 3.3 分歧仲裁的增益稳定（机制稳健性验证）

| | cont | 方案2 仲裁 | 增益 |
| --- | ---: | ---: | ---: |
| 修订前 | 92.31% | 94.61% | **+2.30** |
| 修订后 | 91.30% | 93.65% | **+2.35** |

**增益几乎不变（+2.30 → +2.35）**——说明"分歧仲裁"不依赖具体答案口径，是稳健机制。**方案2 在修订后依然是六方案第一。**

### 3.4 evledger 是唯一涨的（+1.18pp）

`evledger`（整卷通道）是唯一修订后上涨的方案。原因：它的原提示词把"神态字幕"明确列入触发清单，**错得最多**；改判据后受益最大（v2 91.58 vs 修订前 91.2、v5 91.71 vs 88.3）。

### 3.5 方案6（判据修正）改判数骤降

| | 修订前 | 修订后 |
| --- | ---: | ---: |
| 方案6 改判条数 | 358 | **194（−46%）** |

因为 cont 用了新提示词后自己就处理了大部分过判，方案6 这个"事后补救"能改的少了——**印证了"改提示词比事后补救更根本"**。

## 四、结论

1. **改答案 + 改提示词的目标达成**：口径统一、过判减少 61%。
2. **方案2（分歧仲裁）在修订后依然是六方案第一（93.65%）**，且增益稳健（+2.35）。
3. **绝对分下降是口径变严的必然结果**，不代表方案退化；跨口径只能比"相对增益"。
4. **新口径下六方案排序**：方案2（93.65）> 方案3（93.58）> 方案5（92.85）> evledger（92.65）> 方案4（92.60）> 方案6（92.27）≈ 方案1（92.24）> cont（91.30）。
5. **距 95% 的差距在新口径下更大**（方案2 差 1.35pp），因为评分更严——但这也意味着**此前"距 95% 只差 0.39pp"部分来自宽松口径**，新口径是更诚实的基线。
